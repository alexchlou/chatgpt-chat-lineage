# Changelog

## 0.1.0

Initial public English edition of ChatGPT Chat Lineage.

- Searchable naming rules and inspect/apply skill prompts.
- Durable browser save-intent recovery and append-only metadata journal.
- Sourced E0/E1/H relationships, incremental graph snapshots, and offline interactive report.
- Optional Obsidian export and immutable self-addressed email archive.
- Fictional demo, portable configuration and installation, privacy checks, and regression tests.

This is a fresh public repository. Private operational data, local configuration, and historical execution logs are excluded. The public version number is independent of the earlier local skill's versioning.
